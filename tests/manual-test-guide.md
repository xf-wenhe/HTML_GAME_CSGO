# Dust2 路线手动测试指南

## 操作
- 打开 http://localhost:5173
- 点击 **Solo**
- 点击画布锁定鼠标
- `W A S D` 移动，`Space` 跳，`Ctrl` 蹲，鼠标转视角
- `Esc` 暂停

---

## T 方 4 条路线

### 1. T → A Long（A大道）
1. 在 T 老家出生，**往左转 90°**（面朝西）
2. 按 W 沿 A Long 走到底
3. 过 A Doors（灰色门框）
4. 进入 A 包点
5. ✅ 能走通 → 路线 OK

### 2. T → B Tunnels（B洞）
1. 在 T 老家出生，**往右转 90°**（面朝东）
2. 按 W 进入 B Tunnels
3. 穿过下层通道
4. 从 B Tunnels 出口出来
5. 进入 B 包点
6. ✅ 能走通 → 路线 OK

### 3. T → CT（中路）
1. 在 T 老家出生，**往左转 180°**（面朝北，往屏幕上方看）
2. 按 W 沿中路走
3. 穿过 Mid Doors
4. 进入 CT 老家
5. ✅ 能走通 → 路线 OK

### 4. T → A Short（小道/猫梯）
1. 在 T 老家出生，**先按 A 往左走到 A Long 入口**
2. 然后**往左转 180°**（面朝北）
3. 按 W 沿 Short 走（猫梯/高架通道）
4. 从 Short 出来进入 A 包点
5. ✅ 能走通 → 路线 OK

---

## CT 方（需要 CT 出生）

### 5. CT → A Long
从 CT 老家往左走到 A Long → A 包点

### 6. CT → B
从 CT 老家往右走到 B Tunnels → B 包点

### 7. CT → T
从 CT 老家面朝南（默认方向）走中路到 T 老家

### 8. CT → A Short
从 CT 老家走中路，左转走 Short 到 A 包点

---

## 报告格式
每条路线走完后告诉我：
- ✅ 能走通 / ❌ 卡住了
- 如果卡住：卡在什么位置（如"过了 A Doors 后走不动"）
