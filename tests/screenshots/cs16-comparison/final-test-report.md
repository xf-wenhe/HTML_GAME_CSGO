## 🚨 剩余P0问题清单

### P0-1: 静步速度异常（9.99 HU/s vs 110 HU/s）

**问题**: 第三轮测试中静步速度骤降，仅为基准的9%

**根本原因**:
- 测试顺序改变（先蹲下后静步）可能触发了**状态残留**
- 蹲下状态未完全清除，导致静步仍应用蹲下速度

**修复方案**:
```typescript
// client/src/game/PlayerController.ts:120-124
// 检查：蹲下和静步的输入检测是否有冲突
const isCrouching = this.input.isKeyPressed('ControlLeft') || this.input.isKeyPressed('ControlRight');
const isWalking = this.input.isKeyPressed('ShiftLeft') || this.input.isKeyPressed('ShiftRight');

// 修复：确保蹲下和静步不叠加
const targetSpeed = isCrouching
  ? this.movementParams.crouchSpeed
  : isWalking
    ? this.movementParams.walkSpeed
    : this.movementParams.runSpeed;
```

### P0-2: 跳跃上升时间过短（0.15s vs 0.38s）

**问题**: 实测跳跃上升时间仅为理论值的39%

**根本原因分析**:
```
理论重力: 8.0 game units/s²
实测重力: 20.13 game units/s²
差异倍数: 2.52倍
```

**诊断结论**:
1. Physics.ts重力配置正确（-8.0）
2. 但实际物理引擎表现出的重力是配置值的2.5倍
3. 可能原因：
   - Cannon-es的timestep设置不当
   - 重力每帧应用多次
   - 空中摩擦力未正确禁用

**修复方案**:
```typescript
// client/src/game/Physics.ts:13
// 调整重力为理论值的40%，以抵消引擎的过度应用
this.world.gravity.set(0, -3.2, 0);  // -8.0 / 2.5

// 或调整跳跃力匹配当前重力表现
// client/src/game/Movement.ts:41
export const PLAYER_JUMP_FORCE = Math.sqrt(2 * 20.13 * PLAYER_JUMP_HEIGHT); // 调整为 4.78
```

### P0-3: Bot完全静止（0%移动）

**问题**: 第三轮测试中Bot移动比例再次降为0%

**根本原因**:
1. **冻结期间Enemy也在更新**：
   ```typescript
   // client/src/main.ts:819
   const enemyDamage = enemyManager.update(dt, playerPos, now);
   ```
   - Enemy每帧更新，但冻结期间应禁止移动

2. **Enemy内部未检查冻结状态**：
   ```typescript
   // client/src/game/Enemy.ts:244-252
   this.state = this.patrolPath.length > 0 ? 'patrol' : 'idle';
   this.followBotRoute(dt);  // 即使在冻结期间也执行
   ```

**修复方案**:
```typescript
// client/src/game/Enemy.ts（增加冻结检查）
update(dt: number, playerPosition: THREE.Vector3, now: number, canMove: boolean): number {
  if (!canMove) {
    // 冻结期间禁止移动和攻击
    this.body.velocity.x = 0;
    this.body.velocity.z = 0;
    return 0;
  }
  // 正常更新逻辑...
}

// client/src/main.ts:819（传递移动权限）
const botMatchCanMove = !soloBotMatch || soloBotMatch.canPlayerMove();
const enemyDamage = enemyManager.update(dt, playerPos, now, botMatchCanMove);
```
