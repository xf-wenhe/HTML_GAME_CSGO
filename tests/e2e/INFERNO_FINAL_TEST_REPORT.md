4. **地形探索测试** - 验证斜坡、平台高度变化
5. **复杂动作测试** - 验证跳箱子、从高处跳下
6. **地图边界测试** - 验证不会移动到地图外

1. 特定楼梯的上下流畅度

3. 炸弹安放点/拆弹区可到达性
4. 购买区访问路径
