# Dust2 A Site + Mid 精雕设计

日期：2026-05-29

## 目标
在现有 Dust2 重建基础上，仅聚焦 **A Site + Mid** 做一轮高保真精雕，使这两个区域在玩家第一视角下更接近 CS:GO 原版 Dust2 的空间观感、掩体层次和关键视线组织。

本轮范围只包含：
- 几何精雕
- 视觉 props / 灯光 / 材质分区微调

本轮明确不做：
- 新玩法系统
- 网络 / AI / 武器逻辑改动
- 其余区域（B Site / B Tunnels / T Spawn 等）重构
- 完整官方 VMF 逐面逐刷子复刻

---

## 当前问题总结

### A Site 当前问题
1. 平台、Default、Double、Small box 的层次存在，但摆放过于块状，缺少真实叠放感。
2. Goose 目前只是一个高箱 + 小平台延伸，形体仍过于简单。
3. A Ramp 与 A Site 平台之间是可走的，但过渡仍偏机械台阶感，缺少原版那种顺坡接平台的空间感。
4. Short 出 A 的落点组织还不够像原版，缺少“Short 出口 → Default/Goose/平台”的微妙视线控制。
5. Ninja 位置虽然已有，但夹角形体与藏身空间还不够清晰。

### Mid 当前问题
1. Mid 仍偏“通道化”，缺少 Top Mid 两侧房体对空间的挤压感。
2. Xbox 周围墙体仍然过于直接，缺少玩家熟悉的折线与跳点关系。
3. Top Mid → Cat / Mid Doors / CT Mid 的视线组织还不够明显。
4. CT Mid 的开放感与过渡深度不足，仍偏窄、偏平。
5. Mid Doors 周围房体厚度与开口关系还不够像原版 Dust2。

---

## 方案选择

### 方案 1（采用）
**A Site + Mid 逐区块精雕**

做法：
- 保留当前整体坐标、地图比例、路径主结构。
- 在 A Site + Mid 内，把大块几何拆细成更接近原版的局部体块。
- 用更小的碰撞体补齐：转角、落差、平台边沿、箱体层次、墙面折角、门口厚度。
- 同步补小量视觉 props 和局部灯光，使空间更接近原版。

采用原因：
- 最直接提升“看起来像原版 Dust2”的程度。
- 不推翻已有 Dust2 主结构，风险可控。
- 能把这次工作聚焦在你最关心的 A 点与中路。

### 不采用的方案
- **纯视觉精修**：见效快，但结构问题仍然会明显暴露。
- **A Site-only**：Mid 仍会拖累整体观感，无法达成“再做一轮对比”后的明显提升。

## 设计细节

## 1. A Site 精雕

### 1.1 Platform 与掩体层次
A Site 平台保留当前主平台坐标，但会拆细为：
- 平台主体
- 平台前沿压边
- Default 区块基座
- Double stack 叠放层
- Small box 独立偏移块

预期效果：
- 玩家从 Long 看 A，会看到更清晰的箱体层级，而不是一排统一方块。
- 从 Short 出 A 时，Default 与 Double stack 的遮挡关系更像原版。

### 1.2 Goose 形体修正
当前 Goose 过于像单纯高箱。

改进目标：
- 让 Goose 更像一个靠北侧墙体的“高角”结构。
- 增加与 A Site 北墙、平台边缘的衔接块。
- 明确 Goose 前缘与后侧墙之间的贴边关系。

预期效果：
- 玩家会更容易辨认“这就是 Goose”。
- Goose 的 peek 角度更接近原版。

### 1.3 A Ramp → 平台过渡
当前 Ramp 可以走，但更像台阶拼接。

改进目标：
- 在 ramp 顶部增加 2~3 段过渡块。
- 把 ramp 顶与平台接触处做成更自然的“抬升落点”。
- 补 ramp 侧边的挡墙/边缘，使 ramp 更像真正的 A ramp 而非裸露楼梯。

预期效果：
- 从 CT 向 A 推进时，视觉更自然。
- Ramp 顶部不会显得突兀或像直接拼接。

### 1.4 Short 出 A 的视线组织
当前 Short 出口已存在，但出口落点的空间组织不够像原版。

改进目标：
- 给 Short 出口前缘增加小型边墙/矮挡体。
- 修正 Short 出口到 A 平台、Default、Goose 的第一视线落点。
- 让 Short 出 A 后的玩家能自然面对 A box / Goose / 平台，而不是直接看到过多空旷区域。

预期效果：
- A Short 出口更有 CS:GO 那种“落点危险但可读”的感觉。

### 1.5 Ninja 位置
当前 Ninja 位置已有雏形。

改进目标：
- 明确 Ninja 作为“夹角藏身位”的边墙厚度。
- 补 Ninja 地面局部不同材质/阴影 props。
- 保证该位置既能藏，又不会变成夸张的安全点。

---

## 2. Mid 精雕

### 2.1 Top Mid 两侧体量
当前 Mid 更像走廊。

改进目标：
- 增加 Top Mid 左右两侧房体的前压体量。
- 让 Top Mid 更像被两侧建筑挤出来的战斗空间，而不是单纯平地。
- 在 Mid Doors 附近补建筑厚度，使门区更像嵌入墙体。

预期效果：
- 玩家一进入 Mid，会更像 CS:GO Dust2 的 Top Mid 空间。

### 2.2 Xbox 周边折线
当前 Xbox 本体有了，但周边墙线太平。

改进目标：
- 在 Xbox 附近增加 1~2 组折线墙/低挡块。
- 强化 Xbox 到 Cat / Mid Doors 的跳点关系。
- 让 Xbox 周围出现更真实的“卡位/掩体/跳点”几何关系。

预期效果：
- Xbox 不再像孤零零一个箱子。
- Mid 的经典跳箱感更强。

### 2.3 Mid Doors 周边体量
当前 Mid Doors 门框存在，但周边“房体厚度”不足。

改进目标：
- 增强 Doors 开口前后的建筑厚度。
- 给 Doors 附近补两侧延伸面与局部封顶感。
- 让玩家感觉是在“建筑门洞”中穿行，而不是过一组扁平门框。

### 2.4 CT Mid 开阔感
当前 CT Mid 仍略窄。

改进目标：
- 在保持路径不改的前提下，重新组织 CT Mid 两侧墙的视觉体量。
- 通过局部移除/缩减遮蔽块，让 CT Mid 更有向 CT Spawn 和 B 侧展开的感觉。
- 保留可玩性，不大改已建立的路线。

预期效果：
- CT Mid 的空间感更接近原版 Dust2 的“半开放过渡区”。

### 2.5 Top Mid → Cat / Doors / CT 的视线分叉
当前中路的三向分叉感不够强。

改进目标：
- 强调 Mid 中央对三条路径的不同遮挡节奏。
- Cat 方向通过墙体与平台边线体现“上抬路线”。
- Doors 方向通过门洞厚度体现“直穿路线”。
- CT 方向通过远端开口体现“延伸路线”。

---

## 3. 视觉 props 与灯光

### A Site
- 增加平台局部边沿压条感（通过薄 props）
- 加强 A Site 局部天光
- Goose 周围增加更深的明暗对比

### Mid
- Xbox 区域增加更明显的地面/墙体明暗差
- Mid Doors 附近补少量视觉封边
- Mid 区保持比 B Tunnels 更亮，比 A Site 略平

### 本轮不新增大量杂物
为避免把 A Site + Mid 精雕和“全地图环境装饰”混在一起，本轮 props 保持克制，只补直接服务于空间识别的对象。

## 4. 数据与代码边界

本轮只改这些文件：
- `client/src/game/Dust2Layout.ts`
- `client/src/game/MapData.ts`
- `client/src/game/Scene.ts`（只在 Dust2 相关视觉/灯光上改）

不改：
- 网络同步逻辑
- 武器/AI/移动系统
- 非 Dust2 地图

---

## 5. 测试与验证

### 自动验证
- `npm run build` 必须通过

### 手动验证
需要在浏览器中确认：
1. 从 T Spawn 进入 Mid，是否更像 Dust2 Top Mid
2. Xbox 周边是否不再显得空
3. 从 Short 出 A，是否能明显感觉到 Default / Goose / 平台的层次
4. 从 Long 看 A Site，是否比当前更接近原版
5. A Ramp 上 A 的过渡是否自然

### 成功标准
如果完成后能满足以下标准，则认为本轮成功：
- A Site 在第一眼上更像原版 Dust2，而不是“泛化的沙地包点”
- Mid 更像 Dust2 中路，不再像单纯长通道
- Long / Short / Mid 三路进入 A 的空间辨识度提升
- 不引入新的构建错误

---

## 6. 实施顺序
1. 精雕 A Site 平台、Goose、Ramp 顶部过渡、Short 出口、Ninja
2. 精雕 Mid 房体、Xbox 周边、Doors 厚度、CT Mid 空间
3. 补局部 props 与光照
4. 构建验证
5. 第三轮 Dust2 对比

---

## 7. 范围控制
本轮不会试图一次把 Dust2 做成完全 VMF 逐面重建。
目标是把 **A Site + Mid** 从“功能像”推进到“第一视角看上去很像”。

如果这轮完成后仍需继续接近官方 1:1，下一轮再进入：
- B Tunnels 精雕
- B Site 精雕
- 全图贴图分区与污渍层
